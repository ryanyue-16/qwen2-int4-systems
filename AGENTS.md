# Repository instructions

- Use English for all code, comments, docstrings, documentation, and public
  user-facing strings.
- Non-English text is permitted only in language-specific evaluation data or
  regression fixtures where the language itself is under test.
- Preserve the frozen RTN v4 artifact contract and never overwrite versioned
  artifacts or reports silently.
- Do not commit model weights, credentials, private company material, or
  internal hardware diagrams.
- Do not implement or claim Triton, CUDA, or real-LPU performance before the
  documented phase gates are satisfied.
